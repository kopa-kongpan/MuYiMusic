## 文件落位

私钥只放在两处：仓库外的个人备份目录，以及服务器上的 `deploy/secrets/`。

```bash
# 服务器：项目根目录下
cp apiclient_key.pem deploy/secrets/wechat_pay_private_key.pem
chmod 600 deploy/secrets/wechat_pay_private_key.pem
```

`deploy/compose.yaml` 把 `deploy/secrets/` 以只读方式挂载到所有容器的
`/run/secrets/`，因此 `.env` 中保持容器内路径不变：

```dotenv
WECHAT_PAY_PRIVATE_KEY_PATH=/run/secrets/wechat_pay_private_key.pem
WECHAT_PAY_PUBLIC_KEY_PATH=/run/secrets/wechat_pay_public_key.pem
```

### 落库防护

`.gitignore` 已忽略 `*.pem`、`*.key`、`*.p12`、`*.zip`、`.env` 与 `.env.*`。
证书包整个压缩、单独导出私钥、或改名放进任何目录，都不会被提交。若新增密钥
文件类型，必须同步补充忽略规则。

**商户 API 私钥在商户平台无法重新下载。** 遗失只能作废重签，期间支付全部中断。
除服务器外务必另做加密备份。

## 待补充：微信支付公钥

证书包**不包含** `WECHAT_PAY_PUBLIC_KEY_ID` 与 `WECHAT_PAY_PUBLIC_KEY_PATH`，
需在商户平台单独获取：

> 商户平台 → 账户中心 → API安全 → 微信支付公钥 → 申请/下载公钥

公钥 ID 在「管理公钥」页查看，形如 `PUB_KEY_ID_01100000000000000000...`。

### 平台证书与微信支付公钥二选一

两者功能相同，一个商户号只用其中一种。以商户平台实际显示为准：

| 平台显示             | `WECHAT_PAY_PUBLIC_KEY_ID` 填 | `WECHAT_PAY_PUBLIC_KEY_PATH` 放 |
| -------------------- | ----------------------------- | ------------------------------- |
| 只有「微信支付公钥」 | `PUB_KEY_ID_...`              | 下载的公钥 PEM                  |
| 只有「平台证书」     | 平台证书序列号                | 平台证书 PEM                    |
| 两者都有             | 推荐用微信支付公钥            | 无有效期，免轮换                |

本项目的 `_public_key()` 先尝试按公钥解析，失败再回退按 X.509 证书解析，
因此两种材料都能直接使用。

### 高危错误：不要填成商户证书

**`apiclient_cert.pem`（商户自己的证书）不是微信支付公钥，绝不能填进
`WECHAT_PAY_PUBLIC_KEY_PATH`。**

`apiclient_cert.pem` 含公钥部分，能被 `openssl x509 -pubkey` 正常导出，
本项目也能成功加载，因此配置不会报错——但每次向微信发起调用都会验签失败，
表现为 502「微信支付服务暂时不可用」，报错信息不指向根因。二者是不同主体的
证书，不可互换。

## 其余必需参数

| 参数                    | 来源                                                        |
| ----------------------- | ----------------------------------------------------------- |
| `WECHAT_APP_ID`         | 小程序后台，值 `wx30ebb435bb61ba6b`                         |
| `WECHAT_APP_SECRET`     | 小程序后台，用于登录换 openid，支付前置依赖                 |
| `WECHAT_PAY_MCH_ID`     | 商户平台，值 `1750778977`                                   |
| `WECHAT_PAY_API_V3_KEY` | 商户平台自行设置，**必须 32 位**，用于解密回调密文          |
| `WECHAT_PAY_NOTIFY_URL` | 固定路径 `https://muyimusic.net/api/v1/webhooks/wechat-pay` |

`WECHAT_PAY_API_V3_KEY` 设置后平台无法再查看，忘记只能重置，须立即记录到安全位置。

`has_wechat_pay_credentials()` 要求上述参数与两个证书路径**全部非空**，任一缺失
都会返回 503「微信支付尚未配置」。注意 `deploy/compose.yaml` 使用
`${VAR:-}` 形式传参，`.env` 中缺失的键会静默传空字符串——服务照常启动，但支付
必然失败，不会在启动阶段暴露问题。

## 平台侧配置清单

代码与 `.env` 之外，以下三项须在平台确认：

1. **JSAPI / 小程序支付已开通**：商户平台 → 产品中心 → 我的产品，须显示「已开通」。
   商户号与 AppID 绑定 ≠ 产品已开通，二者独立。
2. **小程序 request 合法域名**：微信公众平台配置 `https://muyimusic.net`。
3. **小程序认证完成**：未认证无法使用微信支付。

小程序支付校验的是 AppID 与商户号的绑定关系，**不需要**配置「JSAPI 支付授权
目录」——那是公众号 JSAPI 支付的要求，且只接受已备案 HTTPS 域名，不接受 IP。
