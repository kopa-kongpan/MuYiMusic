# MuYiMusic 第一版门店闭环说明

## 1. 版本信息

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.1 门店闭环 |
| 完成日期 | 2026-08-03 |
| 范围依据 | [第一阶段需求规格](./第一阶段需求规格.md) |
| 开发计划 | [第一阶段开发计划](./第一阶段开发计划.md) |
| 状态 | 可本地联调与演示 |

本版只实现后续业务共同依赖的门店闭环。课程、首页内容、购物车、用户登录、排课、预约和消课未使用模拟接口或静态业务数据占位。

## 2. 已实现内容

后端：

- 管理员账号、角色、权限、门店和审计日志数据模型。
- Alembic 首次 migration 和可重复执行的初始管理员脚本。
- PBKDF2 密码哈希、JWT 登录和 `stores:manage` 权限校验。
- 后台门店分页、搜索、创建、编辑、启用和停用 API。
- 小程序公开门店搜索 API，只返回启用门店；传入坐标后按距离排序。
- 请求 ID、统一 HTTP/校验错误结构、CORS 和写操作审计。

管理后台：

- 管理员登录、会话持久化和过期清理。
- 门店列表、关键词和状态筛选、分页、创建和编辑。
- 门店启停二次确认及加载、空、错误和重试状态。
- 桌面与移动宽度下的响应式布局。

小程序：

- 门店真实接口加载和关键词搜索。
- 定位授权后距离排序和最近门店标识。
- 定位拒绝或失败后继续按门店、城市或地址搜索。
- 联系门店、选择门店和当前门店本地持久化。
- 加载、空结果、网络错误和重试状态。

接口契约：

- OpenAPI 从 FastAPI 导出。
- `packages/api-client` 生成接口类型，并提供后台请求客户端。
- 小程序通过 Taro 请求接口，并复用同一套生成类型。

## 3. 主要接口

| 方法 | 地址 | 权限 | 用途 |
| --- | --- | --- | --- |
| `POST` | `/api/v1/admin/auth/login` | 公开 | 管理员登录 |
| `GET` | `/api/v1/admin/stores` | 管理员 | 查询门店 |
| `POST` | `/api/v1/admin/stores` | `stores:manage` | 创建门店 |
| `PATCH` | `/api/v1/admin/stores/{store_id}` | `stores:manage` | 编辑或启停门店 |
| `GET` | `/api/v1/app/stores` | 公开 | 小程序查询启用门店 |

## 4. 本地运行

### 4.1 Python 与基础设施

项目使用名为 `muyimusic` 的 Conda 环境：

```powershell
conda create -n muyimusic python=3.12 -y
conda activate muyimusic
cd services/api
uv sync --active --group dev
```

复制 `.env.example` 为 `.env`，至少替换数据库密码、`JWT_SECRET` 和 `ADMIN_INITIAL_PASSWORD`。密码和密钥不得提交到仓库。

```powershell
docker compose --env-file .env -f deploy/compose.yaml up -d postgres redis
cd services/api
alembic upgrade head
python -m scripts.bootstrap_admin
uvicorn app.main:app --reload --port 8001
```

当前机器的 `8000` 端口已被其他程序占用，所以后台开发代理默认连接 `http://localhost:8001`。其他环境可以通过 `VITE_API_PROXY_TARGET` 修改后台代理地址。

初始管理员账号来自 `.env` 的 `ADMIN_INITIAL_USERNAME`，默认值为 `admin`；密码只从本地 `.env` 读取。

### 4.2 管理后台

```powershell
pnpm dev:admin
```

默认访问地址为 `http://localhost:5173`。

### 4.3 小程序与 H5

```powershell
pnpm dev:weapp
pnpm dev:h5
```

微信开发者工具导入 `apps/miniapp/dist/weapp`。真实微信环境必须通过 `TARO_APP_API_BASE_URL` 配置已备案的 HTTPS API 域名，并在小程序平台配置服务器域名。

本地 H5 默认请求 `http://127.0.0.1:8001`；用于浏览器验收时可在 `http://127.0.0.1:10086` 提供预览。
