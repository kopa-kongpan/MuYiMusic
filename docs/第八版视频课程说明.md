# MuYiMusic 第八版视频课程说明

## 1. 版本信息

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.8 视频课程 |
| 范围依据 | [第一阶段需求规格](./第一阶段需求规格.md) |
| 开发计划 | [第一阶段开发计划](./第一阶段开发计划.md) |
| 状态 | 已完成本地测试验收 |

本版为小程序引入视频课程：课程商品支持"线下课时课"与"视频课程"两种类型，视频课程按观看权益售卖（不按课时计次），购买后用户可在小程序"我的-我的课程"中按章节观看教学视频。受第一阶段"交易止于购物车、不实现在线支付"的约束，视频课程的购买闭环为：线下成交 → 管理员为学员开通权益 → 学员在小程序观看。

## 2. 已确认规则

- 商品类型为枚举 `course`（线下课时课）与 `video`（视频课程），两种类型在创建时确定，编辑时不可变更。
- 视频课程所有 SKU 的课时数必须为 0（观看权），有效期由 `validity_days` 控制；线下课时课不允许关联视频章节。
- 视频课程至少需要 1 个启用的视频章节才能发布；线下课时课发布时校验启用规格课时数大于 0 且无启用中的视频章节。
- 视频章节包含标题、视频文件、时长（可选）、排序和启用开关，编辑采用全量提交语义：提交中缺失的既有章节会被停用。
- 公开详情只返回章节元信息（标题、时长、排序），不返回播放地址；播放地址只对持有权益的用户通过签名 URL 下发。
- 视频课程权益课时数为 0，不存在"用完"状态，只在生效与过期之间切换。
- 管理员开通权益必须填写幂等键，同一用户 + 同一幂等键重复提交直接返回已有订单，不重复发放。
- 开通权益会同时落库已确认订单、订单明细快照和课程权益，订单明细与权益均透传商品类型与视频章节。

## 3. 已实现内容

### 后端

- `ProductType` 枚举与 `product_type` 列、`product_videos` 表及 `0008` migration（含订单幂等键唯一约束与课时数校验调整）。
- 商品创建/更新支持视频章节持久化与全量同步，媒体键校验区分图片与视频前缀。
- 发布校验、公开详情章节预览（无播放地址）、公开列表章节数统计。
- 对象存储新增 `PRODUCT_VIDEO` 上传目的与 `presigned_get_url` 签名读地址，仅权益读取注入存储以生成播放地址。
- 管理员为用户开通权益接口（`products:manage`），幂等重复提交返回已有订单。
- 共享 `sync_entitlement_status`：视频权益永不进入"已用完"，只在 ACTIVE/EXPIRED 间切换。
- 修复 async 环境 flush 后访问懒加载集合导致的 `MissingGreenlet`：审计快照改为 flush 前求值，商品读取全部预加载视频章节。

### 管理后台

- 商品表单新增商品类型选择（创建时可选，编辑时锁定）。
- 视频课程下 SKU 课时数锁定为 0，并新增视频章节管理：上传 mp4/webm/mov、章节标题、时长、排序与启用开关。
- 商品列表新增类型列，预览抽屉展示视频章节列表与"观看权益"文案。

### 小程序

- 课程详情页：视频课程展示章节预览与"观看权益"文案，提示购买后前往"我的课程"观看。
- 我的课程页：视频课程按章节列出，点击章节进入播放页；线下课时课保持课时进度展示。
- 新增视频播放页：使用 Taro `Video` 组件播放签名 URL，支持章节列表内切换；每次进入重新拉取权益，保证播放地址新鲜可用。

## 4. 主要接口

| 方法 | 地址 | 权限 | 用途 |
| --- | --- | --- | --- |
| `POST` | `/api/v1/admin/stores/{store_id}/users/{user_id}/entitlements` | `products:manage` | 线下成交后为用户开通课程权益 |
| `GET` | `/api/v1/app/me/course-entitlements` | 登录用户 | 我的课程权益（视频课程返回签名播放地址） |

商品创建/更新/发布接口沿用 v0.3 既有路径，`ProductCreate`/`ProductUpdate` 新增 `product_type` 与 `videos` 字段，公开详情新增 `video_chapters` 预览。接口沿用统一错误响应、请求 ID、认证和审计约定。OpenAPI 已重新导出，`packages/api-client` 已重新生成并补充 `ProductType`、`EntitlementVideoChapterRead` 等导出。

## 5. 测试与验收

- 新增视频课程生命周期集成测试：类型与课时校验、无章节不可发布、发布后公开详情只暴露章节元信息、列表章节数统计、全量更新章节（停用/新增）。
- 新增权益开通集成测试：视频课程开通成功、幂等键重复提交返回同一订单、权益课时为 0 且为活跃状态、用户端与管理端权益列表透传章节、无管理权限拒绝。
- 后端 Ruff、格式检查、mypy 与前端管理后台/小程序 lint、typecheck 全部通过；后端全量测试共 21 项通过。
- 公开接口不泄漏视频地址：公开详情与后台列表均不返回 `video_url`，播放地址仅出现在已登录用户的权益响应中（对象存储未配置时为空）。
