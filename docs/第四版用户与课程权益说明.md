本版完成第一阶段 P4 的只读纵向闭环：真实平台身份换码、用户会话、本人订单和课程权益查询、后台按授权门店查询，以及小程序个人中心核心入口。第一阶段交易仍然只到本地购物车，本版不提供订单或课程权益创建接口，也不实现在线支付、退款、发票或人工调整。

## 2. 已实现内容

后端：

- 新增 `users`、`provider_accounts`、`orders`、`order_items`、`course_entitlements` 五张业务表和 Alembic migration `20260805_0004`。
- 平台账号按“平台 + 平台用户标识”唯一关联用户，相同身份重复登录复用同一用户。
- 微信登录调用官方 `code2session`；抖音保留真实换码适配；H5 本地身份只允许在 `APP_ENV=local` 使用，并在保存前进行 SHA-256 哈希。
- 管理员与用户 JWT 明确区分 `admin`、`user` 类型，两个令牌不能跨端混用。
- 用户可读取和修改基本资料，并按门店、状态和分页读取自己的订单与课程权益。
- 订单项保存课程名称、规格、单价、数量、总金额、课时和有效期快照，历史查询不依赖商品当前状态或价格。
- 课程权益保存来源订单项、门店、总课时、剩余课时、有效期和状态；当前没有直接覆盖剩余课时的写接口。
- 新增 `users:read` 权限；后台查询强制校验管理员门店授权，手机号仅返回脱敏值。
- 外部平台网络异常返回可重试的 `503`，无效平台凭证返回 `401`，停用用户不能重新登录或继续使用原令牌。

管理后台：

- 按 `users:read` 权限显示“用户与权益”菜单。
- 支持切换授权门店、按昵称或手机号查询用户、分页和刷新。
- 用户列表展示脱敏手机号、平台来源、订单数、课程权益数和账号状态。
- 详情抽屉只读展示当前门店的订单价格快照、订单项和课程权益，不提供订单、课时或状态修改操作。
- 门店用户列表只包含在该门店已有订单或课程权益的用户；仅登录但尚无门店业务关系的用户不会被归入某一门店。

小程序与 H5：

- 微信和抖音适配器使用 `Taro.login()` 获取临时 code；H5 本地适配器保存稳定的本地设备身份。
- 用户会话使用独立存储，不复用管理后台令牌；会话过期或接口返回 `401` 时清除用户会话。
- 退出登录只清除用户会话，不清除当前门店或门店级本地购物车。
- “我的”页面支持未登录登录入口、登录后基本资料、退出和当前门店切换。
- 新增“我的订单”“我的课程”真实只读列表，按当前门店查询订单和课程权益。
- “我的课表”“我的预约”提供下一阶段真实页面入口，在 P5 数据接入前只显示明确空状态，不生成模拟课表或预约记录。

接口契约：

- FastAPI OpenAPI 已重新导出，`packages/api-client` 已生成用户、订单和课程权益类型。
- 共享客户端提供用户登录、资料、本人订单和课程权益，以及后台用户、订单和权益查询方法。
- 用户调用方和管理后台分别提供自己的令牌来源，避免会话串用。

## 3. 主要接口

| 方法 | 地址 | 权限 | 用途 |
| --- | --- | --- | --- |
| `POST` | `/api/v1/app/auth/login` | 平台临时凭证 | 平台身份换码并建立用户会话 |
| `GET/PATCH` | `/api/v1/app/me` | 用户令牌 | 读取或修改本人基本资料 |
| `GET` | `/api/v1/app/me/orders` | 用户令牌 | 分页读取本人订单 |
| `GET` | `/api/v1/app/me/course-entitlements` | 用户令牌 | 分页读取本人课程权益 |
| `GET` | `/api/v1/admin/stores/{store_id}/users` | `users:read` | 查询授权门店业务用户 |
| `GET` | `/api/v1/admin/stores/{store_id}/users/{user_id}/orders` | `users:read` | 查询用户在指定门店的订单 |
| `GET` | `/api/v1/admin/stores/{store_id}/users/{user_id}/course-entitlements` | `users:read` | 查询用户在指定门店的课程权益 |

本版没有 `POST /orders`、支付、退款、课程权益发放或课时调整接口。购物车数据不能通过公开接口伪造成订单或课程权益。

## 4. 数据与安全规则

- 用户只能通过 `user` 类型令牌访问 `/app/me` 数据，所有查询以令牌中的用户 ID 为强制范围。
- 管理员只能通过 `admin` 类型令牌访问后台，并同时通过 `users:read` 和门店授权校验。
- 订单和课程权益均包含明确门店归属；后台查询固定追加当前门店条件。
- 订单金额使用整数分，订单项保留购买时快照。
- H5 本地身份仅用于本地 Docker 联调，生产环境请求会被拒绝。
- 微信、抖音 AppSecret 只存在后端配置中，不进入前端构建产物。
- 完整手机号不进入后台列表响应，日志和文档不记录 access token 或真实密钥。
