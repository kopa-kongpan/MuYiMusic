## 2. 已实现内容

后端：

- 新增门店首页内容模型、管理员门店授权关系和 Alembic migration `20260804_0002`。
- 支持图片、视频和快捷入口的创建、编辑、启停、展示时间及事务排序。
- 公开门店首页只返回启用且处于展示时间内的内容，不暴露对象 key、后台状态和审计字段。
- 平台管理员可管理全部门店；门店运营账号只能读取和修改已授权门店。
- 新增 `store_content:manage` 权限，内容创建、修改和排序均写入审计日志。
- 提供 S3v4 兼容的对象存储直传签名，校验 MIME、文件大小和门店对象 key 前缀。
- 对象存储未配置时上传凭证接口返回 `503`，不使用本地或模拟上传降级。

管理后台：

- 首页内容列表支持门店、类型和状态筛选。
- 支持创建、编辑、直传上传、预览、启停和上下移动排序。
- 类型或状态筛选生效时禁用排序，防止只重排可见子集造成顺序冲突。
- 菜单按 `store_content:manage` 权限显示，并适配桌面和移动宽度。

小程序：

- 选择门店后进入对应门店首页，内容随当前门店切换。
- 展示图片、视频和快捷入口，媒体加载失败时可重试。
- 支持内部页面与 WebView 跳转。
- 提供首页、课程、预约、我的四项底部导航，微信、抖音和 H5 共用业务实现。
- H5 在未配置 tab 图标时不渲染空图片节点，避免浏览器出现破图。

接口契约：

- OpenAPI 已从 FastAPI 重新导出。
- `packages/api-client` 已更新首页内容、上传凭证和公开门店首页类型及请求方法。
- 管理后台与小程序复用同一套生成类型。

## 3. 主要接口

| 方法 | 地址 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/api/v1/admin/stores/{store_id}/home-content` | `store_content:manage` | 查询门店首页内容 |
| `POST` | `/api/v1/admin/stores/{store_id}/home-content` | `store_content:manage` | 创建首页内容 |
| `PATCH` | `/api/v1/admin/stores/{store_id}/home-content/{content_id}` | `store_content:manage` | 编辑或启停首页内容 |
| `PUT` | `/api/v1/admin/stores/{store_id}/home-content/order` | `store_content:manage` | 批量更新展示顺序 |
| `POST` | `/api/v1/admin/media/upload-tickets` | `store_content:manage` | 生成对象存储直传凭证 |
| `GET` | `/api/v1/app/stores/{store_id}/home` | 公开 | 获取门店信息和当前可展示内容 |

## 4. 对象存储配置

图片和视频由管理后台直接上传到 COS、OSS、TOS 或其他 S3 兼容对象存储。服务端只生成限时签名并保存 object key，不代理文件内容。

`OBJECT_STORAGE_ENDPOINT` 必须填写对象存储供应商提供的 **S3 兼容 API Endpoint**。不要填写对象存储控制台地址、普通网页地址或 CDN 访问域名。CDN 或公开访问域名单独填写在 `OBJECT_STORAGE_PUBLIC_BASE_URL`。

关键配置：

```dotenv
OBJECT_STORAGE_PROVIDER=cos
OBJECT_STORAGE_ENDPOINT=https://供应商提供的-S3-兼容-Endpoint
OBJECT_STORAGE_REGION=区域标识
OBJECT_STORAGE_BUCKET=存储桶名称
OBJECT_STORAGE_ACCESS_KEY_ID=访问密钥标识
OBJECT_STORAGE_SECRET_ACCESS_KEY=访问密钥
OBJECT_STORAGE_PUBLIC_BASE_URL=https://媒体访问域名
OBJECT_STORAGE_ADDRESSING_STYLE=virtual
```

`OBJECT_STORAGE_PROVIDER` 支持 `cos`、`oss`、`tos` 和 `s3`。如供应商要求 path-style 访问，将 `OBJECT_STORAGE_ADDRESSING_STYLE` 改为 `path`。临时凭证可通过 `OBJECT_STORAGE_SESSION_TOKEN` 配置。

默认允许的图片格式为 JPEG、PNG、WebP 和 GIF，最大 10 MiB；视频格式为 MP4、MOV 和 WebM，最大 200 MiB。限制可通过 `.env` 调整。生产环境应同时配置存储桶 CORS，允许管理后台域名执行带签名请求头的 `PUT` 上传。

## 5. 本地运行与迁移

Python 统一使用 Conda 环境 `muyimusic`：

```powershell
conda activate muyimusic
cd services/api
uv sync --active --group dev
alembic upgrade head
python -m scripts.bootstrap_admin
uvicorn app.main:app --reload --port 8001
```

管理后台和目标小程序分别运行：

```powershell
pnpm dev:admin
pnpm dev:weapp
pnpm dev:tt
pnpm dev:h5
```

微信开发者工具导入 `apps/miniapp/dist/weapp`，抖音开发者工具导入 `apps/miniapp/dist/tt`。真机环境必须配置已备案的 HTTPS API 域名和对象存储上传域名。
