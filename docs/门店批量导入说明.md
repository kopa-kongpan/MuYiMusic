# 门店批量导入说明

日期：2026-10-23。来源为用户提供的 `门店.xlsx`。

## 数据处理

- 工作表有 338 条门店记录，字段为门店名称、区域、详细地址；所有记录的三个字段均非空，名称和完整地址均无重复。
- 城市取“区域”，区县和街道门牌从 `省份>城市>区县>详细地址` 拆出。线上原有 2 家门店保留，导入后共 340 家营业中门店。
- 表格未提供电话和经纬度。新门店的 `phone` 保存为空字符串，`latitude`、`longitude` 保存为数据库 `NULL`。公开接口对此不计算距离；管理后台显示“未提供”，H5 隐藏无电话门店的拨号入口。
- 导入使用确定性 UUID 和名称、城市、区县、地址查重；事务内校验暂存表数量，重复执行不会增加记录。导入 SQL 与备份只保存在服务器受限发布目录，不进入 Git。
