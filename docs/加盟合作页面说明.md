# 加盟合作页面说明

## 功能范围

- 管理后台新增“加盟合作”，具有首页内容管理权限的运营人员可按授权门店维护页面。
- 每个门店独立保存主标题、合作介绍、合作优势、支持政策、申请流程、联系人、电话和微信。
- 页面支持草稿和发布状态；只有已发布内容可通过公开接口读取。
- 小程序及 H5 底部导航在“课程”和“预约”之间提供独立“加盟合作”页面，支持电话咨询和下拉刷新。
- 加盟页内置品牌主视觉、全国门店、品牌介绍、经营成果、自研教材、合作权益和咨询二维码素材；经营成果支持横向滑动，所有图片均可点击查看大图。
- 图片在进入小程序包前统一压缩为适合移动端展示的尺寸；重复图、目录页和章节分隔页不进入包体。
- 后台尚未创建配置时展示使用当前门店电话的默认加盟内容；保存草稿后隐藏，发布后展示自定义内容。

## 接口

| 方法  | 路径                                        | 说明                              |
| ----- | ------------------------------------------- | --------------------------------- |
| `GET` | `/api/v1/admin/stores/{store_id}/franchise` | 读取后台配置，未创建时返回 `null` |
| `PUT` | `/api/v1/admin/stores/{store_id}/franchise` | 创建或覆盖门店加盟合作配置        |
| `GET` | `/api/v1/app/stores/{store_id}/franchise`   | 读取已发布的公开页面              |

## 内容填写约定

合作优势、支持政策和申请流程均使用“一行一项”。前端过滤空行后分别显示为编号列表、支持列表和流程步骤。
