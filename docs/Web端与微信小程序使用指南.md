# Web 端与微信小程序使用指南

本指南面向门店运营人员、学员和教师。Web 端指 MuYiMusic 运营后台；微信小程序是学员选课、购买、预约及教师查看排课的入口。后台中的「使用指南」页面提供同一流程的简版说明。

## 一、Web 运营后台

### 登录与权限

1. 打开运营后台，使用分配的账号和密码登录。
2. 左侧菜单按账号权限展示。若看不到某个功能，请联系平台管理员核对角色、权限及授权门店。
3. 多数内容以门店为单位维护。编辑前确认页面上当前选择的门店，避免改错门店。
4. 页面右上角的书本按钮或左侧「帮助 → 使用指南」可随时打开页面内说明；右上角退出按钮用于结束登录。

### 建议的首次运营顺序

1. **门店管理**：新增或编辑名称、城市、地址、营业信息及启用状态。启用后，门店才会出现在小程序选店页。经纬度、电话等未提供的资料可以留空，但缺少经纬度的门店无法按距离准确排序。
2. **首页内容**：选择门店，维护图片、视频和快捷入口，设置启用状态及展示时间，预览后到用户端检查。
3. **加盟合作**：按门店填写介绍、优势、支持政策、申请流程和联系方式；保存并发布后在小程序「加盟合作」查看。
4. **课程商品**：先维护分类，再创建课程商品和规格，核对价格、图片及购买条件，最后发布。归档商品不再作为正常在售商品维护。
5. **视频课程**：需要视频教学时，为对应门店维护视频课程及课时内容，并检查启用状态与可播放资源。学员播放还需有效课程权益。
6. **排课管理**：先在「教师管理」维护教师，再创建排课，核对课程、教师、开始时间、容量和开放状态。暂停或取消后，用户端可约资源会随之变化。

### 日常运营

| 菜单       | 常见操作                                           | 核对重点                                 |
| ---------- | -------------------------------------------------- | ---------------------------------------- |
| 门店管理   | 查找、编辑、启用或停用门店                         | 门店名称、地址与状态                     |
| 首页内容   | 调整顺序、预览、启停内容                           | 当前门店及展示时间                       |
| 加盟合作   | 编辑并发布门店合作页                               | 联系方式和发布状态                       |
| 课程商品   | 管理分类、规格与商品状态                           | 价格、图片、上架状态                     |
| 视频课程   | 维护课程、课时与视频                               | 课时启用状态和播放资源                   |
| 排课管理   | 管理教师和可约时段                                 | 时间、教师、容量及开放状态               |
| 预约与消课 | 查看预约，取消、正常消课、登记缺席及撤销消课       | 学员、课程与实际到课情况；操作会影响课时 |

## 二、微信小程序

### 学员使用流程

1. **选择门店**：首次打开时在「选择门店」搜索门店名称、城市或地址。允许定位时，有经纬度资料的门店可按距离排序；未授权定位也可以手动搜索和选店。
2. **浏览课程**：从「首页」或底部「课程」进入列表，查看分类和课程详情。底部「加盟合作」可查看当前门店发布的合作信息。
3. **加入购物车**：在课程详情选择规格和数量，加入购物车；结算前核对课程、数量和实时价格。
4. **登录与支付**：按页面提示完成微信登录，在微信小程序内发起支付。支付结果同步可能需要片刻，可在「我的 → 我的订单」查看最终状态。浏览器 H5 不支持微信小程序支付。
5. **查看权益**：在「我的 → 我的课程」查看已获得的课程与课时。需要视频学习时，从课程入口进入可用视频课时；播放取决于有效权益。
6. **预约上课**：在底部「预约」选择日期和可约排课。预约需要对应的有效课程权益及可用课时；成功后到「我的 → 我的预约」查看，按页面规则取消。
7. **查看个人信息**：「我的」还提供排课、消息等入口。手机号绑定需要小程序版本及微信授权支持，可按页面提示操作。

### 教师使用流程

1. 在「我的 → 教师工作台」进入教师入口。
2. 首次使用时输入管理员提供的教师绑定码，关联教师身份。
3. 选择教师身份后查看当天预约与消息；需要取消学员预约时，先核对学员和课程，再按页面提示确认。

## 三、常见问题

| 现象               | 检查方法                                                                           |
| ------------------ | ---------------------------------------------------------------------------------- |
| 找不到门店         | 在小程序搜索城市或地址；运营人员检查后台门店是否启用。未填写经纬度只影响距离排序。 |
| 看不到课程或排课   | 检查当前选店、商品发布状态、教师与排课的开放状态，以及是否处于可约时间。           |
| 不能预约           | 先确认已登录、持有对应课程的有效权益，且课时与名额足够。                           |
| 支付后订单仍未确认 | 稍后刷新「我的订单」；持续异常时记录订单信息，联系运营人员核查。                   |
| 收不到微信提醒     | 检查是否在小程序中允许订阅消息；也可到「我的 → 消息」查看站内消息。                |
| 后台没有某个菜单   | 请平台管理员检查账号角色、功能权限和授权门店。                                     |

## 四、发布说明

Web 后台的使用指南随服务器中的管理前端更新。微信小程序代码更新需要另行构建、上传并按微信流程审核发布；服务器发布不会自动替换用户手机上的小程序版本。微信支付、手机号授权和订阅消息的可用性，以实际小程序版本及微信侧配置为准。
