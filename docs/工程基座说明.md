# 工程基座说明

## 边界

- `apps/miniapp` 与 `apps/admin` 不共享 UI，只依赖共享 API 类型、枚举和纯函数。
- `services/api/app/api` 只承载 HTTP 路由和响应组织。
- 后续业务逻辑进入 `services`，数据访问进入 `repositories`。
- 微信、抖音及支付差异分别通过前端 `platform` 与后端 `providers` 适配层隔离。
- 所有数据库结构变更必须通过 `services/api/migrations` 管理。

## 当前状态

当前已完成 v0.6 预约与消课闭环：

- FastAPI 已实现管理员/用户双令牌认证、RBAC、门店授权、审计、门店、首页内容、课程商品、本人订单与课程权益、教师排课、预约与消课 API。
- PostgreSQL migration 当前为 `20260805_0006`，Redis 和异步任务基座已配置。
- 对象存储支持 S3v4 兼容直传，首页媒体与商品图片按门店和用途隔离。
- 管理后台已实现门店、首页内容、课程分类、商品、教师、排课、预约和消课维护，以及按授权门店查询用户、订单和课程权益。
- 小程序已实现门店选择、门店首页、课程浏览、详情、实时购买校验、门店级本地购物车、平台登录、个人中心、我的订单、我的课程、我的课表、我的预约和在线预约。
- 微信和抖音登录差异位于前端 `platform` 与后端 `providers`；H5 设备身份只允许本地联调并在服务端哈希保存。
- OpenAPI 生成类型由 `packages/api-client` 统一提供给管理后台和小程序。

订单与课程权益仍没有公开创建、支付或人工调整接口。预约会锁定权益课时，消课与缺席在课程结束后扣减，撤销消课保留原记录并恢复课时；预约、排课和权益通过数据库行锁与幂等键保持一致性。
