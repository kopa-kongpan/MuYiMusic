# 工程基座说明

## 边界

- `apps/miniapp` 与 `apps/admin` 不共享 UI，只依赖共享 API 类型、枚举和纯函数。
- `services/api/app/api` 只承载 HTTP 路由和响应组织。
- 后续业务逻辑进入 `services`，数据访问进入 `repositories`。
- 微信、抖音及支付差异分别通过前端 `platform` 与后端 `providers` 适配层隔离。
- 所有数据库结构变更必须通过 `services/api/migrations` 管理。

## 当前状态

当前已完成 v0.3 课程商品闭环：

- FastAPI 已实现管理员认证、RBAC、门店授权、审计、门店、首页内容、课程分类与商品 API。
- PostgreSQL migration 当前为 `20260804_0003`，Redis 和异步任务基座已配置。
- 对象存储支持 S3v4 兼容直传，首页媒体与商品图片按门店和用途隔离。
- 管理后台已实现门店、首页内容、课程分类和商品维护。
- 小程序已实现门店选择、门店首页、课程浏览、详情、实时购买校验和门店级本地购物车。
- OpenAPI 生成类型由 `packages/api-client` 统一提供给管理后台和小程序。

尚未实现真实小程序登录、订单、支付、课程权益、排课、预约和消课；这些能力按 P4-P5 推进，不使用模拟业务数据代替。
