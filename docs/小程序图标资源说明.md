# 小程序图标资源说明

## 来源与处理

- 图标来自产品方提供的 `慕义音乐图片展示.png` 九宫格原图。
- 原图按 3 行 3 列拆分为 9 张独立 PNG，2026-10-22 统一重新居中，并补齐 16 张同风格 PNG（其中 6 张来自此前扩展设计，10 张为本次生成）。25 张资源均为 `144 × 144`，存放在 `apps/miniapp/src/assets/icons/muyi/`。
- 图标保留原始深蓝、白色版画风格；页面展示时使用圆形裁切，避免方形白底露出。

## 图标映射

| 文件                     | 小程序用途                           |
| ------------------------ | ------------------------------------ |
| `home-deer.png`          | 首页底部导航、门店选择页和首页品牌标 |
| `franchise-deer.png`     | 加盟合作底部导航                     |
| `course-note.png`        | 课程底部导航                         |
| `my-courses.png`         | 音乐音符备用图标                     |
| `schedule.png`           | 个人中心“我的课表”入口和课表状态     |
| `headphones.png`         | 个人中心“我的课程”入口               |
| `teacher.png`            | 个人中心“教师工作台”入口             |
| `profile.png`            | “我的”底部导航和未登录状态           |
| `franchise-deer-alt.png` | 加盟合作页品牌章                     |

构建时由 `apps/miniapp/config/index.ts` 将图标目录复制到各平台产物的 `assets/icons/muyi/`。

| `orders.png`              | 我的订单入口、订单与订单详情状态  |

| `store.png`               | 门店列表与门店快捷入口            |

| `cart.png`                | 课程加购、购物车入口与空状态      |
| `search.png`              | 课程搜索                          |

| `check.png`               | 加盟支持列表与成功提示            |

| `piano.png`、`guitar.png` | 钢琴、吉他分类；声乐沿用麦克风    |

页面新增图标优先使用 `components/AppIcon.tsx` 与 `assets/icons.ts` 的映射；图片为装饰，旁边保留文字，纯图标按钮须在按钮上提供无障碍名称。首页快捷入口按标题和跳转页面选择本地圆章；内容区图片仍按后台配置展示。未知课程分类回退至音符，不再使用首字占位。

底部导航活动文字改为深蓝。章节序号、数量和业务状态文案继续保留。
